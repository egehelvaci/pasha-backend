## System Overview
The Pasha Backend is a comprehensive REST API system for carpet sales and management, including:
- User authentication and management
- Product catalog and inventory
- Shopping cart operations
- Order management and processing
- Payment integration
- Admin panel functionality
- Employee tracking and management
- QR code based delivery system
- Store and address management
- Notification system
